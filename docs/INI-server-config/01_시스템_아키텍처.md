# FEP 시스템 아키텍처 - AP서버 / 시세서버

## 1. 전체 구조 (2-Tier)

```
                           ┌──────────────────┐
                           │    KRX 거래소      │
                           │  10.147.110.161   │
                           │  10.147.110.21    │
                           └────────┬─────────┘
                                    │
                     TCP(주문/체결) + UDP(시세 Multicast)
                                    │
                     ┌──────────────┴──────────────┐
                     │      시세서버 (PB 모듈)       │
                     │   채권 KRX 직접연결 전담       │
                     │   활성 프로세스: 2개           │
                     └──────────────┬──────────────┘
                                    │
                     TCP (7개 포트: 41001~42002, 16511)
                                    │
                     ┌──────────────┴──────────────┐
                     │      AP서버 (PA 모듈)        │
                     │   주문처리/전략/Client 전담    │
                     │   활성 프로세스: 32개          │
                     └──────────────┬──────────────┘
                                    │
                     TCP (5개 포트: 32001~32018)
                                    │
                             ┌──────┴───────┐
                             │  Client/HTS  │
                             └──────────────┘
```

## 2. 역할 분담

| 서버 | 모듈 | 프로세스 | 역할 | 외부 연결 |
|------|------|---------|------|----------|
| 시세서버 | PB | 4개 (활성 2) | KRX 직접 TCP/UDP 연결, 시세 수신, 주문/체결 중계 | KRX (10.147.110.x), KRX MC (233.38.231.x) |
| AP서버 | PA | 75개 (활성 32) | 주문처리, 체결관리, 자동매매, Client 서비스 | 시세서버, KOSCOM (172.18.120.105 등), Client |

## 5. 특이사항

1. **KOSCOM KTS 경로 비활성**: proc.ini에서 KOSCOM 경유 KRX 접속(pa_1301_ts KTS, pa_1201_tr KTS 등) 전부 주석 처리. 시세서버 직접연결만 사용
2. **Auto Strategy 전부 비활성**: 40개 모두 Status=S. 계좌별 선택 활성화 구조
3. **시세서버 경량화**: 시세수신 + 로그관리만 담당. 주문/체결은 tcp2.ini에 KRX 포트만 정의
4. **이중화**: KRX 주문 2회선, 체결 2회선, 장운영 2회선, TCP 시세수신 2채널
