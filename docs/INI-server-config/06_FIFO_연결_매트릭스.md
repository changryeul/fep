# FIFO 연결 매트릭스

## 1. FIFO 개요

- **총 FIFO/파일 정의**: 119개 (file.ini)
- **프로세스 간 IPC**: FIFO(Named Pipe) 기반
- **메커니즘**: 소스 프로세스가 OFN(Output File Name)으로 쓰고, 대상 프로세스가 IFN/FFN으로 읽음
