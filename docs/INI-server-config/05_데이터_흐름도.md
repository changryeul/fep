```
Client                AP서버                       시세서버              KRX
  │                     │                             │                   │
  │──TCP:32011──▶│      │                             │                   │
  │              pa_8201_tr                            │                   │
  │              │                                    │                   │
  │              ├─OFN→ pa_1301_ts                    │                   │
  │              │      │──TCP:41001──▶│               │                   │
  │              │      │              │(주문 중계)    │                   │
  │              │      │              │──TCP:37721──▶│                    │
  │              │      │              │              │  KRX 주문접수      │
  │              │                                    │                   │
  │              ├─OFN→ pa_6001_mp (조회처리)          │                   │

  │              └─OFN→ pa_50xxx   (Auto전략 제어)     │                   │
```
