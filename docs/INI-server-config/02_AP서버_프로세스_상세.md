## 7. Auto Strategy (40개, 전부 S)

4그룹 x 10개 = 40개 프로세스. 모두 동일 패턴.

| 그룹 | 프로세스 범위 | Proc # |
|------|-------------|--------|
| Auto1 | pa_50101mp ~ pa_50110mp | 23~32 |
| Auto2 | pa_50201mp ~ pa_50210mp | 33~42 |
| Auto3 | pa_50301mp ~ pa_50310mp | 43~52 |
| Auto4 | pa_50401mp ~ pa_50410mp | 53~62 |

### 공통 패턴 (각 프로세스 동일)

```
입력: IFN = pa_50{G}{NN}mp, FFN = pa_50{G}{NN}mp1
출력: OFN_1 = pa_8101_ts  (Client 통보)
      OFN_2 = pa_9001_mp  (한도 체크)
      OFN_3 = pa_1301_ts  (주문 발주)
시간: 08:00 ~ 23:00
```

### 연결 관계

```
pa_1201_mp (응답) ──OFN──▶ pa_50xxx ──OFN──▶ pa_8101_ts (Client)
pa_1401_mp (체결) ──OFN──▶ pa_50xxx ──OFN──▶ pa_9001_mp (한도)
pa_8201_tr (Client수신) ──OFN──▶ pa_50xxx ──OFN──▶ pa_1301_ts (주문)
pa_9001_mp (한도) ──OFN──▶ pa_50xxx
```
