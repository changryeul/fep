## 2. 시스템 아키텍처 설계

### 2.1 전체 구조 (2-Tier)

```
                        ┌──────────────┐
                        │   KRX 거래소  │
                        │ 10.147.110.x │
                        └──────┬───────┘
                               │
                    TCP(주문/체결) + UDP(시세 Multicast)
                               │
                ┌──────────────┴──────────────┐
                │      시세서버 (PB 모듈)       │
                │   채권 KRX 직접연결 전담       │
                │   프로세스: 4개               │
                └──────────────┬──────────────┘
                               │
                    TCP (7개 포트: 41001~42002, 16511)
                               │
                ┌──────────────┴──────────────┐
                │      AP서버 (PA 모듈)        │
                │   주문처리/전략/Client 전담    │
                │   프로세스: 75개              │
                └──────────────┬──────────────┘
                               │
                    TCP (5개 포트: 32001~32018)
                               │
                        ┌──────┴───────┐
                        │  Client/HTS  │
                        └──────────────┘
```

### 2.2 역할 분담

| 서버 | 모듈 | 역할 | 외부 연결 |
|------|------|------|----------|
| 시세서버 | PB | KRX 직접 TCP/UDP 연결, 시세 수신 | KRX (10.147.110.x), KRX Multicast (233.38.231.x) |
| AP서버 | PA | 주문처리, 체결관리, 자동매매, Client 서비스 | 시세서버, KOSCOM (172.18.120.105, 192.168.151.x), Client |

## 7. FIFO 연결 매트릭스 설계

### 7.1 주문/체결 계열

```
[소스 프로세스]          [FIFO Name]        [대상 프로세스]
─────────────────────────────────────────────────────────
pa_1401_tr (:41002) ──→ pa_1201_mp ──→ pa_1201_mp (응답)
                    ──→ pa_5201_qs ──→ pa_5201_qs (Q응답)

pa_1402_tr (:41003) ──→ pa_1201_mp ──→ pa_1201_mp (응답)
                    ──→ pa_1401_mp ──→ pa_1401_mp (체결)
                    ──→ pa_5201_qs ──→ pa_5201_qs (Q응답)
                    ──→ pa_5401_qs ──→ pa_5401_qs (Q체결)

pa_1403_tr (:41004) ──→ pa_1601_mp ──→ pa_1601_mp (장운영)

pa_1411_tr (:41005) ──→ pa_7801_dd ──→ pa_7801_dd (RDS01)
                    ──→ pa_7802_dd ──→ pa_7802_dd (RDS02)
```

### 7.2 처리 → 배분 계열

```
pa_1201_mp ──→ pa_50101mp~50410mp (40개 Auto전략)
           ──→ pa_8101_ts (Client송신)

pa_1401_mp ──→ pa_50101mp~50410mp (40개 Auto전략)
           ──→ pa_8101_ts (Client송신)

pa_1491_mp ──→ pa_9001_mp (한도제어)
           ──→ pa_1492_mp (에러처리)
```

### 7.3 Auto전략 출력 (공통 패턴)

```
pa_50xxx (40개 동일 패턴):
  OFN_1 → pa_8101_ts (Client 통보)
  OFN_2 → pa_9001_mp (한도 체크)
  OFN_3 → pa_1301_ts (주문 발주)
```

## 9. 특이사항 및 주의점

### 9.1 비활성 경로
- **KOSCOM KTS 경로**: AP서버 proc.ini에서 pa_1301_ts(KTS주문), pa_1201_tr(KTS체결) 등 KOSCOM 경유 KRX 접속 프로세스가 전부 주석 처리

- **pa_6001_mp(조회처리)**: Status=S

- TCP 시세수신: 2개 (pa_7622_tr:16511, pa_7623_tr:42002)
