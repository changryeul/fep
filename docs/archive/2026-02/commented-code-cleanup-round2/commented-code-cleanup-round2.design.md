```c

/* 2번째 */                                  // DELETE from here (828)
#if defined B1201
/*
    rt = F_W ((p_flag+2) * 10, ...);
    ...
*/
#endif                                       // DELETE to here (845)

    Log (USR_OK, "file write[...]", ...);   // stays (line 847)
```

**참고**: 847줄의 `OFN(D_K,P_K,p_flag-1+2)`는 B1201 쓰기가 제거될 때 잠재적으로 유효하지 않은 파일 슬롯을 참조합니다. 이는 라우팅 제거 후의 기존 기능 문제 (오래된 참조)이며, 이 정리 범위가 아닙니다.
