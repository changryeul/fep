# 계획: sub-commented-code-final

## 개요

3개 sub/ 소스 파일에서 마지막 남은 `/* */` 주석 처리된 코드 블록을 제거합니다. sub/ 공유 라이브러리의 최종 정리 통과 — 이 후 sub/는 주석 처리된 데드 코드가 없을 것입니다. 함수 변화 없는 순수 삭제.

## 문제

`commented-code-cleanup-round2` (14개 파일에서 213줄) 후, 모든 sub/*.c 파일의 전체 스캔은 6개 `/* */` 블록이 3개 파일에서 총 ~39줄로 남아있음을 보여줍니다. 이들은 더 새로운 구현으로 대체된 이전 함수 호출입니다:

1. **`inet_addr` → `inet_pton`** — IPv6 호환 버전으로 대체된 더 이상 사용되지 않는 함수
2. **`sprintf` 직접 struct → `sprintf(Tmp,...) + memcpy`** — 버퍼 오버플로우 안전 패턴
3. **`msgrcv` 큐 플러시 루프** — 생성 시 비활성화된 큐 버퍼 정리

모든 원본 코드는 버전 제어 및 BACK2025/ 백업에 보존되어 있습니다.

|------|---------|------|---------|-------------|
| C01 | 29-31 | `/* */` | `/* address.sin_addr.s_addr = inet_addr (p_ip_addr); */` | 줄 32의 `inet_pton(AF_INET, p_ip_addr, &address.sin_addr.s_addr);` |
| C02 | 59-61 | `/* */` | `/* address.sin_addr.s_addr = inet_addr (p_ip_addr); */` | 줄 62의 `inet_pton(AF_INET, p_ip_addr, &address.sin_addr.s_addr);` |

### 파일 3: sub/queue.c (6줄)

| 항목 | 줄 | 유형 | 내용 | 대체 |

## 접근 방식

### 방법

각 파일에 대해 주석 처리된 블록을 삭제합니다. 다른 변경은 없습니다. 줄 번호를 보존하기 위해 각 파일 내에서 하향식으로 작업합니다.

### 구현 순서

1. file_rw.c (3 블록, 27줄) — 가장 큰 대상, 하향식: F03 → F02 → F01
2. tcpip_connect.c (2 블록, 6줄) — C02 → C01
3. queue.c (1 블록, 6줄) — Q01
