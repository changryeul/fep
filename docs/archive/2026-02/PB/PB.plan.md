# PB 모듈 코드 품질 감사 — 계획 문서

> **요약**: PB (채권 KRX FEP) 모듈의 종합적인 코드 품질 감사 및 수정 — 10개 소스 파일에 걸친 28개 발견사항
>
> **프로젝트**: FEP (KRX Front-End Processor)
> **작성자**: Claude Code
> **날짜**: 2026-02-26
> **상태**: 초안

---

## 1. 개요

### 1.1 목표

종합 감사를 통해 발견된 PB 모듈(`st01/src/PB/`)의 모든 남은 코드 품질 문제를 수정합니다. 이전 PDCA 사이클에서는 시스템 전체 문제(데드 코드, strcpy, getenv, 신호 안전성 등)를 다루었지만 PB 고유의 버그는 여전히 남아 있습니다. — 실시간 거래 데이터 무결성에 영향을 주는 3개의 CRITICAL 이슈 포함.

### 1.2 배경

FEP 코드베이스 전체에 걸쳐 33개 기능이 완료되었습니다. 이 감사는 시스템 전체 패스에서 다루지 않은 모듈 고유의 버그를 포착하기 위해 10개의 PB 소스 파일에 특별히 중점을 둡니다. PB 모듈은 주문 전송, 응답 수신, 체결 처리, 시장 데이터 및 클라이언트 통신을 위한 채권 고유의 KRX 거래소 연결을 처리합니다.

### 1.3 관련 문서

- 아키텍처: `docs/FEP_Architecture_Analysis.md`
- PA/PB 중복 제거: `docs/archive/2026-02/pa-pb-dedup*/`
- 이전 정리: `docs/archive/2026-02/_INDEX.md` (33개 완료 기능)
