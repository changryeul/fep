# 설계: header-cpp-comment-c89

> 10개의 활성 헤더 파일에서 모든 C++ 스타일 주석 (`//`)을 C89 블록 주석 (`/* */`)으로 변환.

## 참조

- 계획: `docs/01-plan/features/header-cpp-comment-c89.plan.md`

## 범위 요약

`st01/inc/`의 10개 활성 헤더 파일에서 243개의 C++ 주석. 제로 기능 변경.

## 변환 규칙

```
// comment text   →   /* comment text */
```

**예외**: `fep_sub.h`의 데드 주석 처리 코드 (6개 라인) → 변환 대신 **삭제**.
