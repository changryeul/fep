# 계획: header-cpp-comment-c89

> 엄격한 ANSI C 준수를 위해 활성 헤더 파일의 모든 C++ 스타일 주석(`//`)을 C89 블록 주석(`/* */`)으로 변환합니다.

## 1. 배경 & 동기

FEP 코드베이스는 순수 C89/ANSI C(CLAUDE.md 규칙)를 대상으로 합니다. `inc/` 의 헤더 파일에는 10개 활성 파일에 걸쳐 243개의 C++ 스타일 `//` 주석이 있습니다. 대부분의 최신 C 컴파일러가 `//`를 허용하지만, HP-UX/AIX 대상의 엄격한 C89 모드(`-ansi`, `-std=c89`)는 이를 거부할 수 있습니다. 이전 정리 사이클에서는 `.c` 파일의 주석 처리된 데드 코드를 제거했으며, 이 기능은 `.h` 파일의 나머지 C++ 주석 스타일을 해결합니다.

## 3. 변환 규칙

| 패턴 | 이전 | 이후 |
|---------|--------|-------|
| 줄 끝 주석 | `int x;  // description` | `int x;  /* description */` |
| 독립형 라인 주석 | `// section header` | `/* section header */` |
| 주석 처리된 코드 | `// #include <foo.h>` | `/* #include <foo.h> */` |
| 주석 처리된 코드 (데드) | `// char field[9];` | `/* char field[9]; */` |

**fep_sub.h 참고**: 24-27행 (`// #include <libxml/...>`) 및 95, 100행 (`// #define _XOPEN_SOURCE 700`)은 데드 코드입니다. 이전 사이클에서 이미 `.c` 파일에서 주석 처리된 데드 코드를 정리했으므로, 이 6개 행은 변환보다는 **삭제**되어야 합니다. 이는 프로젝트 규칙과 일치합니다.
