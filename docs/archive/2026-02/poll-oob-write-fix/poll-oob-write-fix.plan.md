## 1. 개요

### 1.1 목적

배열이 `struct pollfd Poll[2]`로 선언되어 있을 때 (유효 인덱스: 0, 1) `Poll[2]`에 쓰는 것으로 인한 버퍼 오버플로우 버그를 수정합니다. 이전에 수정된 `poll-buffer-overflow-fix` (pb_7200_tr.c)와 동일한 버그 클래스이지만 `Poll[2]` 대신 `Poll[1]`.

### 1.2 배경

이 파일들은 공통 조상 (예: `pa_1100_ts.c` 또는 `pb_1100_ts.c`)에서 포크되었는데, 이는 `Poll[3]`을 올바르게 선언하고 모든 3개 인덱스를 사용합니다. TR 변형이 생성되었을 때, 배열 크기가 `Poll[2]`로 축소됨 (2개 이벤트 소스만 필요) 하지만 INPUT_FD에 대한 데드 `Poll[2]` 초기화는 남겨졌습니다.

- `Poll[0]` = START_FD (FIFO) — `Init_Parameters()`에서 설정
- `Poll[1]` = Sockfd (소켓) — `Device_Open_Logon()`에서 설정 (fep_common.c:348)
- `Poll[2]` = INPUT_FD — **데드 코드**: 인덱스 2에 대한 switch case 없음, `PollCnt`가 3에 도달하지 않음

### 1.3 관련 문서

- 이전 수정: [poll-buffer-overflow-fix](../../archive/2026-02/poll-buffer-overflow-fix/) (pb_7200_tr.c Poll[1] OOB)
- 공유 함수: `sub/fep_common.c` — `Device_Open_Logon()`이 `Poll[1].fd = Sockfd` 설정
