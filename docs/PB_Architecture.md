# PB 모듈 구성도

> **PB** (Bond KRX Direct FEP) — 채권 KRX 직접접속 시장FEP
>
> 프로세스 총 18개 (proc.ini 기준), 소스 10개 (+PW 공유 2개)
>
> **참고**: 현재 운영 설정에서는 모든 PB 프로세스가 Status=S (비활성), PA가 KRX 직접접속으로 운영 중.
> PB는 PA와 KRX 사이에 위치하는 시장FEP로, PA(간접FEP)와 분리 운영 시 활성화됨.

---

## 1. PA/PB 관계 및 역할

```
┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  [현재 구성] PA 직접접속 (PB 비활성)                                      │
│                                                                          │
│    Client(HTS/MTS) ──── PA(간접FEP) ════════════════ KRX(거래소)         │
│                                                                          │
│                                                                          │
│  [PB 활성 구성] PA ↔ PB ↔ KRX                                           │
│                                                                          │
│    Client(HTS/MTS) ──── PA(간접FEP) ──── PB(시장FEP) ════ KRX(거래소)   │
│                          :41001~41005      :37221                        │
│                          :32009,32016      :57221                        │
│                          :32019            :61725,61726                  │
│                                            :63724,63725                  │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
```

**동일 포트 사용**: PA와 PB는 KRX 측 동일 포트(37221, 57221, 61725, 61726, 63724, 63725)를 사용.
PB 활성 시 PA는 PB의 Client 포트(41001~41005, 32009, 32016, 32019)로 접속.

## 5. IPC 구조

### 5.1 FIFO (Named Pipe) 데이터 흐름

```
  주문 경로:
    PA/Client(:41001) ──TCP──► pb_1301_tr ──FIFO──► pb_1101_ts ──TCP──► KRX(:37221)

  에러 경로:
    pb_1101_ts ──FIFO──► pb_1401_ts ──TCP──► PA/Client(:41002)

    KRX(:61725) ──TCP──► pb_1601_tr ──FIFO──► pb_1403_ts ──TCP──► PA/Client(:41004)

  RDS 수신 경로:
    KRX(:63725) ──TCP──► pb_7801_tr ──FIFO──► pb_1411_ts ──TCP──► PA/Client(:41005)

  일괄 송신 경로:

    KRX ──UDP──► pb_7102/7103_ur ──FIFO/SHM──► pb_7102/7103_dd ──► SHM
```
