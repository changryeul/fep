## 4. IPC 구조

### 4.1 FIFO (Named Pipe) 데이터 흐름

```
  주문 경로:
    Client(8201) ──DSHM──► 주문TS(1101/2101) ──TCP──► KRX

  응답 경로:
    KRX ──TCP──► 응답TR(1201/2201) ──FIFO──► 응답MP(1201/2201_mp)
                                              ├── FIFO → Client송신(8101)
                                              └── DSHM → Auto전략(50xxx)

  체결 경로:
    KRX ──TCP──► 응답TR(1201/2201) ──FIFO──► 체결MP(1401/2401_mp)
                                              ├── FIFO → Client송신(8101)
                                              ├── DSHM → Auto전략(50xxx)
                                              └── FIFO → 한도(9001)

  시세 경로:
    KRX ──UDP/TCP──► 시세UR/TR(7xxx) ──FIFO──► 시세DD(7xxx_dd)
                                                └── SHM (시세 공유메모리)
```
