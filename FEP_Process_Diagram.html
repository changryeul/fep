전체 아키텍처 요약 (채권 전용):

① 거래소(KRX) ↔ FEP ↔ AP — 주문/응답/체결:
AP(ap53) → TCP:32011 → pa_8201_tr(수신) → FIFO → pa_5001_qr(큐) → FIFO → pa_1101_ts(송신) → TCP:37221 → KRX
KRX → TCP:57221 → pa_1201_tr(수신) → FIFO → pa_1201_mp(응답) / pa_1401_mp(체결) → FIFO → pa_8101_ts(송신) → TCP:32001 → AP

② 코스콤 UDP → 시세서버 → AP — 시세:
코스콤(233.38.231.x) → UDP멀티캐스트(:10402/:10406) → 시세서버 → 가공 → AP(ap53/63)
※ FEP(pa_7xxx_us) UDP시세송신은 모두 Status=S → FEP가 AP로 시세를 직접 보내지 않음

③ FEP → 시세서버 — 채권체결/호가:
FEP pa_7622_tr(서버소켓:42001) / pa_7623_tr(서버소켓:42002) → 시세서버에서 접속하여 채권체결호가/M4 데이터 수신

④ AP는 2개 서버와 인터페이스: FEP(주문/응답/체결) + 시세서버(시세/호가)

운영 현황: 총 111개 프로세스 중 Status=R 약 55개 | TCP2: 28포트 | UDP: 12채널 | FIFO: 77개 | TCP1: 2마스터(P:35010, B:45010)
접속 클라이언트: ap53/ap63(업무계), at04(테스트), TS, OS, IA, IB, BLTS(NY/Frankfurt), PK시스템 (client.ini 화이트리스트)
